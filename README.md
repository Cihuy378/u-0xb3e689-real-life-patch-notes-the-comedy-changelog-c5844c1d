## Why this line

It makes the reader wince and laugh at once, which is exactly the brief. The phrasing stays in the terse register of a real release note — a version number, "fixed a bug where", and a fix stated as if it shipped — and the second sentence ("Sleep now takes priority over cringe") is a second changelog-style beat that uses the 160-character budget well instead of padding. The year 2014 keeps it specific: a dated, concrete memory reads as a real lived-in bug, not a generic complaint.
